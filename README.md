# Work Study Project – Cinar Kaucuk

## Project Overview

Industrial Engineering study conducted in a rubber packaging operation.

## Methods

- Method Study
- Time Study
- Work Sampling
- Pareto Analysis
- Fishbone Diagram
- Process Flow Analysis

## Findings

- 41.6% of errors originated from a single operation
- Process reduced from 17 to 15 steps
- 25% idle time identified

## Recommendations

- Layout improvement
- Better work distribution
- Packaging redesign

## Tools

- Excel
- Industrial Engineering Methods
